# Paradise Nursery Shopping Application

**Repository:** `e-plantShopping`

Paradise Nursery is a responsive houseplant shop built with React, Vite, and Redux Toolkit. Browse four categories of plants, add items to a cart, change quantities, remove products, and see the order total update immediately.

## Run locally

```bash
npm install
npm run dev
```

## Build and deploy

```bash
npm run build
npm run deploy
```

The Vite build is configured for the GitHub Pages project URL `https://balintexeyt.github.io/e-plantShopping/`.

## Main features

- Landing page with a Paradise Nursery welcome and company overview.
- Plant catalog with four categories and six distinct plants in each.
- Redux-powered cart with quantity controls, removal, subtotals, and an order total.
- Responsive navigation with Home, Plants, and a live cart quantity.
- Checkout placeholder message for future development.
